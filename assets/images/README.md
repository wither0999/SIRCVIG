# Imágenes del Sistema

## Logo de la Empresa
Coloca aquí el logo de tu empresa con el nombre `logo.png` o `logo.jpg`

## Imagen de Fondo
Para la página de login, coloca una imagen de fondo con el nombre `background.jpg`

### Recomendaciones:
- **Logo:** Dimensiones recomendadas: 200x200px, formato PNG con fondo transparente
- **Fondo:** Dimensiones recomendadas: 1920x1080px, formato JPG

Los archivos deben estar en esta carpeta: `assets/images/`
