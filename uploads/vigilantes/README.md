# Carpeta de Uploads de Vigilantes

Esta carpeta almacenará los documentos subidos de los vigilantes.

**Estructura automática:**
```
uploads/vigilantes/
└── {cedula_vigilante}/
    ├── Foto_*.jpg
    ├── CedulaEscaneada_*.pdf
    └── Antecedentes_*.pdf
```

Los archivos se organizan automáticamente por cédula del vigilante.

**IMPORTANTE:** Esta carpeta debe tener permisos de escritura.
